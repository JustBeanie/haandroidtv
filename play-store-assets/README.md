# Play Store assets

These files are ready for the Google Play Console listing for version 0.3.0:

| File | Dimensions | Source |
| --- | ---: | --- |
| `app-icon-512x512.png` | 512 x 512 | Deterministic raster rendering of the installed app's cyan house/keyhole mark. |
| `feature-graphic-1280x720.png` | 1280 x 720 | Center-cropped final generated marketing artwork. |
| `screenshots/01-setup.png` | 1920 x 1080 | Actual Compose setup UI on the Android TV API 36 emulator. |
| `screenshots/02-dashboard.png` | 1920 x 1080 | Actual Compose dashboard UI with synthetic demo entities. |

The screenshots are generated by `PlayStoreScreenshotTest`. Its settings,
server URL, token, labels, and entity values are test-only fixtures. Re-run the
capture and visually review the outputs whenever the release UI changes.

The feature graphic was created with the built-in image generation tool using
this final prompt:

> Create a polished 16:9 Google Play feature graphic for an Android TV
> smart-home remote-control app. Center a simple cyan house silhouette with a
> white circular keyhole/light motif and surround it with four restrained
> floating tiles suggesting a light bulb, thermostat, window blinds, and a
> security shield. Use a deep navy background, soft cyan glow, subtle geometric
> grid, generous safe margins, and a crisp premium 3D/vector-hybrid style. Use
> no text, people, device frames, remotes, brand logos, unsupported claims, or
> watermarks.

`source/feature-graphic-generated.png` preserves the selected generated source.
Run `tools/prepare-play-store-assets.ps1 -FeatureSource <path>` to recreate the
exact listing sizes and the deterministic app icon.
